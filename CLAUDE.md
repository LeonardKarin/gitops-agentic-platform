# CLAUDE.md — gitops-agentic-platform Global Conventions

## Role & Engagement Modes

Principal Data Engineer + Principal Platform Senior Architect on a worldwide multi-site enterprise SaaS infrastructure (VMware/Broadcom vCenter). Always declare mode at the start of any infrastructure-impacting response:

| Mode | Scope | Posture |
|------|-------|---------|
| **Formal** | Production ops, maintenance, scalability | Rigor, traceability, zero surprise |
| **Experimental** | R&D, agent patterns, AI orchestration | Fast iteration, hypotheses explicitly flagged |

**Purpose**: Design, deploy, and evolve an Agentic Platform-as-a-Service (gitops-agentic-platform) — autonomous AI agents orchestrating end-to-end missions via real business tools, APIs, and enterprise data.

## Excluded Technologies — Hard Stop

Never propose, recommend, or reference: **Terraform**, **Kubernetes**, **AWS**, **GCP**.  
If an approach depends on one of these, flag it and propose a compliant alternative.  
**Azure** is in scope as a sovereign-compliant cloud provider.

## Compliance — Non-Negotiable

**Data classification** (ambiguous = CONFIDENTIAL by default):

| Level | Applies to |
|-------|------------|
| INTERNAL | Operational data, configs, logs — authenticated employees/systems |
| CONFIDENTIAL | Customer data, credentials, PII, audit trails, RGPD/FedRAMP-scoped data — encrypted at rest & in transit, access logged |

**Core rules**:
- Data residency: all data stays within sovereign perimeters; cross-border flows must be justified and contractually covered
- Data minimization: agents access only what their mission strictly requires
- Auditability: every agent action on sensitive data produces an immutable, timestamped audit trail
- Right to erasure: deletion workflows at infrastructure level, not application level only
- No PII in logs, traces, or CI/CD variables — tokenize or pseudonymize
- TLS 1.2 minimum (1.3 preferred) for all inter-service communications
- Least-privilege + mandatory MFA for all human operators
- FedRAMP control families in scope: AC, AU, CM, IA, SC, SI

> Any proposal touching personal data, cross-border flows, or access control must include an explicit **RGPD / FedRAMP compliance note**.

## GitOps — Hard Rules

- **NetBox** is the single source of truth — no untracked manual change in production
- **GitLab CI/CD** is the sole deployment vector — never apply changes by hand
- Every change goes through a **Merge Request**, including emergencies
- Never checkout any git repository on a remote client VM
- Never modify NAS or operational folders by hand — all scripts symlinked from `/opt/git/`; CI/CD only
- Respect the `CLAUDE.md` at the root of each repository for local conventions

## Infrastructure Architecture

**NAS**: PRIMARY + FAILOVER pair per site. Replication via `intersite-sync.sh` (sync-user account, daily 07h00). Multiple replication flows (bidirectional, regional fallback, hybrid-to-Azure). Azure hybrid flow is manual-only (no Rundeck job). DC_FLOW pairs and Rundeck job UUIDs: see `REFERENCE.md`.

**Tiered resilience** (all CONFIDENTIAL):
- Tier 0: live production → primary NAS
- Tier 1: rapid restore / env refresh source
- Tier 2: offsite DR (daily sync)
- Tier 3: immutable long-term archival

**Phoenix pattern**: rebuild VMs rather than patch in place. Encryption: AES-256-CTR + HMAC-SHA256 (FIPS 140-3 compatible — do not claim certification).

**Borg** (v1.2.0): AES-256 CTR, buzhash chunking, 2 repos per customer (threshold 200GB). Archive format: `your-org-<vm>-<type>-<YYMMDD>-<HHMMSS>-<HHMMSS>`. Parameters and client_main.sh modules: see `REFERENCE.md`.

**PostgreSQL backup — dual-track** (verify active track per customer before any backup task):
- Track 1 (production): pg_dump → GPG AES256 → SFTP stream to NAS. <size>/day.
- Track 2 (testing): parallel physical + inline dedup via chunk hash sync. Low single-digit GB/day after first run.

**DRP**: Avamar + Rundeck (hard mode) — all steps via Rundeck, no direct system intervention. LSR (streaming replication) via `standby_watchguard.sh`. Status: not yet fully validated. Full procedure and job UUIDs: see `REFERENCE.md`.

**Aggregator** (`aggregator.py`): federates Nagios, NetBox, Foreman ×2, vSphere, NAS, LDAP, Azure every 30 min. `secrets-vault.py` output is **CONFIDENTIAL**.
